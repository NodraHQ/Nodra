How Nodra Works

Every mechanic, limit, timer and rule on the platform today - documented, not summarized.

Academy

Free, self-paced courses on blockchain and Web3. Ten modules, one quiz each, one badge per module completed.

Structure

Academy has 10 modules, in a fixed order: Blockchain, Wallets, Networks, Assets, DeFi, Lending, Yield, Stablecoins, Security, and Final Project. Each module is a self-contained reading page ending in a quiz. There's no enrollment step and no prerequisite check - any module can be opened directly, though the content is written assuming you've read the ones before it.

Quizzes

Every module ends with a quiz covering that module's content. The quiz is complete once every question has been answered at least once - it doesn't require a perfect score, and there's no time limit or attempt limit. Retaking a quiz is always allowed and never removes a badge already earned.

Badges

Finishing a module's quiz grants that module's badge automatically, the moment the last question is answered. This only works if you're logged in - the page checks your session at that exact moment. If you're not logged in, the quiz still completes normally, but a message tells you to log in to claim the badge; nothing is queued or retroactively granted after logging in later.

Show Down

Live, host-paced trivia. Everyone sees and answers the same question at the same time - speed decides the score, not just correctness.

How a round works

The host controls the pace: pick a question pack, launch a question, wait for answers (or the timer), reveal the correct one, move to the next. Every player answers on their own phone, scanning the room's QR code or entering the room code to join.

Scoring

Points depend on how fast you answer, not just whether you're right. Answering within the first 3 seconds of a question earns the full 1,000 points. After that, points decay in a straight line down to 300 points right at the time limit. A wrong answer earns 0, no matter how fast it was.

Rounds

When a question set ends, the host can start a new round from the results screen. Starting a new round archives the current scoreboard under "Previous Rounds" and resets scores to zero for the next one - past rounds stay visible for reference, but don't carry points forward into the new round.

Time Attack

A shared countdown timer. Correct answers add time, wrong ones take it away - the room keeps playing until the clock runs out.

How it works

Everyone in the room shares the same timer. Players answer questions at their own pace on their phones; each correct answer adds time to the room's clock, each wrong answer subtracts from it. The game ends when the shared timer hits zero, whenever that happens.

Tap Rush

Pure speed. No questions - just tapping as fast as possible, in one of three modes the host picks.

Race mode

Everyone races to a tap target. First to reach it wins. Default target: 60 taps, with a 30-second cap - whoever has the most taps when time runs out wins if nobody reaches the target first.

Infinite mode

No target - just tap as many times as possible before time runs out. Ranked by total tap count when the timer ends.

Tug of war mode

Players split into two teams by join order (first half Team A, second half Team B). Each tap pulls the rope toward your team; the team that pulls it all the way, or has it further their way when time runs out, wins. Default duration: 20 seconds.

Roulette

Gather names, spin a wheel, draw a winner. Built for picking someone out of a group, not for answering questions.

Where names come from

Three sources, host's choice:

  • Import from a previous room - pulls the participant list from an earlier Show Down, Time Attack, Tap Rush or Quest Drop room by its code
  • QR room - opens a live room people join with their phones, same as the other games
  • Paste a list - type or paste names directly, no room needed

Spinning

The host spins the wheel to draw one winner at a time. There's a toggle, on by default, to remove each winner from the wheel after they're drawn - with it on, nobody can win twice in the same session; turning it off lets the same name be drawn again on a later spin.

Quest Drop

Envelope-based challenges for live events. Pick a difficulty, open an envelope, answer correctly, claim what's inside.

Difficulties

Every envelope is tagged Easy, Medium, or Hard before the event starts - the difficulty is visible on the envelope, the prize inside isn't, until it's opened and answered correctly.

Two ways to set up prizes

  • List mode - the host defines a fixed stock of prizes per difficulty ahead of time; each correct answer draws from that stock until it runs out
  • Budget mode - the host sets a total budget and a percentage split across the three difficulties (plus how many envelopes total), and envelopes are generated automatically from that split

Branding

Quest Drop supports both the built-in default look and any custom theme the host has access to (see Custom Themes) - sponsor branding on the envelopes and screen is part of what the game was built for.

Badges

A single badge system shared across the whole platform - Academy, NDQuest, and VIP all grant and display the same kind of badge.

What a badge is

A badge has a name and description in both languages, a shape, and either an uploaded image or an icon-and-color combination - never both at once. It also has a color behind the icon (or no background at all, if it's image-based) and an icon size, as a percentage of the badge's frame.

Shapes

  • Classic - the default shield outline
  • Rounded - a softer version of the shield
  • Hex - six-sided, pointed top and bottom
  • Coin - octagon, coin-like
  • Square - rounded square
  • Circle - plain circle

An uploaded image is never cropped to fit these shapes - the shape and background only apply to icon-based badges. An image-based badge shows exactly what was uploaded, with a transparent background.

Icons

Fourteen built-in icons are available for badges without an uploaded image: trophy, award, medal, crown, shield, star, gem, flag, zap, target, rocket, sparkles, heart, and book-open. If a badge has neither an icon nor an image, it falls back to showing the first letter of its name.

Who can create a badge

Any active VIP can create badges from their account page, up to a tier-based limit per cycle: Bronze 10, Prata 20, Gold 30. Renewing VIP resets the count back to the tier's full limit - it doesn't carry over unused slots from the previous cycle. A created badge isn't automatically given to anyone; the VIP who made it grants it to specific people afterward, with an optional note attached to explain why.

Featured badges

Everyone chooses up to 3 badges to feature on their public profile and in-game name tag, from their own profile page. Picking none means none show - there's no automatic fallback to showing everything you own.

Claiming a badge by QR code or link

A VIP can generate a claim code for any badge they created, shown as both a QR code and a plain link. Anyone logged in who scans it or opens the link gets that badge instantly - if they aren't logged in yet, logging in completes the claim automatically right after. Each code can optionally have a maximum number of uses, an expiry date, both, or neither (no limit at all until the VIP pauses or deletes it by hand). A badge can have several active codes at once - useful for running one per event.

Academy badges

The 10 Academy module badges are granted automatically by the system itself when you finish the matching module's quiz - they have no VIP owner, unlike every other badge on the platform (see the Academy section).

Where badges show up

Every badge you hold appears on your public profile. Inside NDQuest games, badges show as small icons next to your name during play - at that size, the badge is always shown at its real shape (not forced into a circle), just scaled down.

VIP

A monthly membership paid in stablecoin, directly from your own wallet - no card, no middleman holding funds. There are three tiers: Bronze, Prata, and Gold, each unlocking a bigger live room and more of everything else.

Tiers and pricing

Bronze
$5/month - live rooms up to 100 players
Prata
$20/month - live rooms up to 250 players
Gold
$50/month - live rooms up to 1,000 players, priority support

One payment covers 30 days. Paying again before the current period ends extends it - the new 30 days are added on top of the existing expiry date, not from the moment of payment, so paying early never wastes time. Paying for a different tier while already VIP switches you to that tier's price and limits going forward.

How payment works

There's no checkout page or card form. Pick a tier, then send the exact amount from your own wallet to Nodra's treasury address, and paste the transaction hash back into the site. The instant a valid, unused hash is submitted, the blockchain is checked and VIP is activated right away - there's no waiting period or review step. The only limit is on how old that transaction can be: it has to have happened within the last 48 hours, or it's rejected as too old, even if it was genuinely paid.

Accepted networks and tokens

  • Avalanche C-Chain - USDT
  • Base - USDC
  • Solana - USDC or USDT

Each transaction hash can only be used once, ever - reusing one, even on a different account, is rejected.

Live room limits

Every live room (Show Down, Time Attack, Tap Rush, and Roulette's live QR mode) is capped by however many players can join at once, based on whoever's hosting. Free accounts cap at 30 players and 10 hosted rooms every 30 days - VIP of any tier removes the monthly room cap entirely, and raises the per-room player cap to whatever the tier allows. Pasting a name list into Roulette, or Quest Drop's single-screen mode, never count toward any of this - nobody's device needs to connect for those.

Only one active room at a time is allowed per account, across all four live games - starting a new one while another is still open is blocked until the first closes. This keeps a single VIP account from hosting several big rooms simultaneously.

Custom Themes

Rebrand any NDQuest game with your own colors and logo. Three stages: create it private, optionally submit it for everyone to use, get it reviewed.

Creating a theme (private, included in VIP)

Any active VIP can create private themes at no extra cost, up to a tier-based limit per renewal cycle: Bronze 3, Prata 10, Gold unlimited. Each one starts out private - visible only to the VIP who made it, usable in their own game rooms. If your VIP has no expiration date on file (an admin-granted VIP, not a paid one), the limit applies forever instead of resetting per cycle.

How a theme is built

You pick two base colors - a primary and a background - and the system derives a full palette of 13 colors from those two (lighter/darker variants, text colors, borders, and so on), so the whole game re-themes consistently from just two picks. Six of those derived colors can be manually overridden by hand if the automatic result isn't quite right. A logo is optional (PNG, SVG or WebP); without one, the game falls back to showing the theme's name as text.

Which games it applies to

Each theme is scoped to specific games - when creating it, you choose which of the five NDQuest games it should apply to. It only shows up as an option in those games, not automatically in all of them.

Submitting for public review ($10)

A private theme can be submitted so any host can use it, not just its creator. This costs $10, paid the same way as VIP - your own wallet, any of the accepted networks, transaction hash pasted back for verification (see VIP for the full payment mechanics, including the 48-hour verification window).

Paying moves the theme to pending review. An admin then approves or rejects it:

  • Approved - status becomes public, visible to any host in the games it's scoped to
  • Rejected - status becomes rejected, with a written reason. The $10 already paid isn't lost or charged again: the theme can be edited and resubmitted for review for free, as many times as needed

What happens if VIP lapses

A public theme only stays visible to other hosts while its creator's VIP is currently active. If the creator's VIP expires, the theme stops showing up for everyone else immediately - it isn't deleted, and comes back automatically the moment VIP is renewed.

Question Packs

A saved set of custom questions a VIP can reuse across rooms, and optionally submit for the team to review and add to the official catalog every game can use.

Who can create one

Saving a pack is a VIP-only benefit, tier-limited: Bronze 5, Prata 20, Gold unlimited saved packs at a time (not per cycle - deleting an old one frees up a slot). Accounts without VIP can still type custom questions when hosting a room, same as always - they just aren't saved or reusable afterward. A pack can be created two ways: checking "save this pack" while hosting Show Down, Time Attack, or Quest Drop with custom questions typed in, or creating one directly from the profile page without hosting anything.

Private by default

Every pack is private the moment it's created - visible only to the VIP who made it, listed as an option the next time they host a room in one of the games it applies to. A single pack can apply to more than one game at once. Nobody else, VIP or not, can see or use someone else's saved pack unless it gets approved into the public catalog.

Submitting for public review

From the "My Packs" screen, any not-yet-submitted (or previously rejected) pack has a "Submit for review" button. Once submitted, only the VIP who owns it and the admin team can see it while it's pending - no other VIP browses or reviews other people's submissions. The admin approves or rejects it; approving adds it to the official catalog every game can pull from, rejecting sends it back to being a normal private pack with a reason attached, free to edit and resubmit as many times as needed.

Creating one

Questions can be typed one block at a time, pasted, or uploaded as a .txt file, using the same PERGUNTA/RESPOSTAS/CORRETA format across every game. Quest Drop packs can optionally tag each question with a difficulty (easy/medium/hard); if none are tagged, the pack still works in Quest Drop, it just draws questions at random instead of balancing by difficulty.

Support

A direct chat with the team for anyone with an account - open a ticket, get a reply, keep the conversation going in the same thread.

Who can use it

Any logged-in account, VIP or not. There's no support option for people without an account - the tab simply isn't shown until you're logged in.

How it works

Each ticket is its own conversation with a subject line, so a new question about something different gets its own thread instead of mixing into an old one. Messages arrive live - no need to refresh the page to see a reply come in. Once the team closes a ticket, that thread stops accepting new messages; open a new one if you need more help.
